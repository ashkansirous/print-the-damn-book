Support

Something not working? Start with the notes below, then write to ashkan.sirous@gmail.com and say what you saw and which printer you use.

Naming your pages

Put the images in one folder and name them Cover, 1, 2 and so on up to Back cover. The app sorts them in that order and tells you if a page is missing or if blank pages are needed to make up whole sheets.

Printers that cannot print two-sided

If your printer has no two-sided mode, choose Manual two-sided. The app sends the fronts first, then asks you to turn the stack over and reload it, then sends the backs. It never prints one-sided by accident.

Backs print upside down or in the wrong order

Print a test sheet first. It shows which edge the paper flips on. If the backs are upside down, switch the flip edge in the options and print the test sheet again.

Folding the booklet

Stack the sheets in the order they print, fold the whole stack in half, and the pages read in order from the cover to the back cover.

Windows SmartScreen

A new, unsigned app can trigger a SmartScreen notice. Choose More info, then Run anyway. The source is public on GitHub.

Bugs and requests

Open an issue on GitHub or send an email.
