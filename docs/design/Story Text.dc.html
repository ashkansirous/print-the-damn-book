Right-to-left books, Dino's store, and hand-over from Dino Reader

The app's own screens never mirror; only the book does. A Reading direction switch sits beside the language select; spreads, text-page sides and the As printed sheets flip with it, and each text picks its own direction and font (Vazirmatn for Arabic script). The store is a dialog off the Open step; a hand-over from Dino Reader lands on the same loading state as any open.
